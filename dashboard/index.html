📱 QR code

🔑 Pairing code

Alternative to QR. Enter your phone number and type the code on your phone.

Format

Any of these work: 2347074455500 · +2347074455500 · 07074455500 (uses country code 234). No spaces or dashes.

—

For — — enter in WhatsApp → Linked Devices → Link with phone number instead

Pairing tip: the code and QR refresh live (dashboard polls every 5s). Enter the CURRENT code within ~60s; scan the QR within ~20s of it appearing.

Settings

Webhook integration to keep the bot alive & receive events

🔔 Webhook

The bot POSTs JSON events to your URL with an HMAC-SHA256 signature header (X-WaBot-Signature) when a secret is set. A webhook that replies 200 OK is also the classic "keep-alive" ping for free hosting tiers.

Media is downloaded with yt-dlp (YouTube, Instagram, TikTok, Vimeo, Dailymotion, SoundCloud and 1000+ sites). Videos over ~15 MB or 30 s are delivered as document files due to WhatsApp's video-message limits.
